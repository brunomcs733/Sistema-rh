# Sistema de RH para Pequenas Empresas

Projeto de faculdade - Sistema de gestão de recursos humanos.

## Estrutura
- `/frontend` - Aplicação React
- `/backend` - API Python/Flask
- `/database` - Scripts SQL
- `/docs` - Documentação

## Funcionalidades
- Login com perfis (RH, Cliente, Funcionário, Candidato)
- Cadastro de usuários
- Consultas (relatórios)
- Edição de registros
- Exclusão lógica
- Ativação/Desativação de contratos
